# Results

This directory holds compact reviewer-friendly analytical outputs generated by the pipeline.

Expected outputs include:
- `analysis_summary.json`
- `asset_engineering_priority.csv`
- `top_25_engineering_priorities.csv`
- `lifecycle_cost_scenarios.csv`
- `capital_allocation_selected_assets.csv`
- `capital_allocation_summary.csv`

Do not commit large or sensitive utility extracts. Public result files should be small, auditable, and appropriate for publication.
