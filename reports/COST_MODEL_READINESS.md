# Cost Model Readiness

## Ready now
The repository has a documented place for planning-level replacement cost, lifecycle scenario factors, discount rate, O&M assumptions, and capital-budget scenarios.

## Required before utility-specific cost conclusions
- locally relevant rehabilitation/replacement unit costs
- project scope definitions by asset class
- mobilization, bypass pumping, traffic control, restoration, contingency, and engineering assumptions
- escalation basis and estimate year
- current bid history or published benchmark sources
- treatment of bundled projects and shared mobilization costs

## Model boundary
The starter lifecycle model is appropriate for transparent scenario screening. It is not a Class 1–3 engineering estimate, design estimate, or bid prediction.

All verified cost inputs should be documented in `sources/SOURCE_REGISTER.md` and configuration files before use in public findings.
