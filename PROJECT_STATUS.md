- input validation and automated unit tests for the baseline risk model
- raw and processed data placeholders
- project charter, data dictionary, and method notes

## Framework now established
- source-data ingestion and QA path
- configuration-driven risk assumptions
- SQL quality checks

- lifecycle-cost analysis structure

- reviewer-facing results, figures, reports, and source register

## Next analytical milestones
1. Connect a real or representative wastewater asset inventory.
2. Define local condition, failure, capacity, and consequence scoring rules.
3. Calibrate LoF/CoF using inspection and maintenance evidence.
4. Build ranked asset and project portfolios.
5. Add rehabilitation/replacement cost benchmarks.
6. Produce maps, figures, and capital-program scenarios from validated data.

## Important limitations
- no utility-specific production dataset is committed to this public repository
- the baseline 1–5 LoF/CoF framework is a starting point and requires local calibration
- planning-level cost models are not final engineering estimates or bids
- hydraulic, structural, environmental, and operational review remains necessary before project decisions

## Repository rule
Raw, intermediate, sensitive, and restricted utility data stay local or in approved storage. Public code, methods, compact result extracts, figures, and reports may be versioned here when appropriate.
