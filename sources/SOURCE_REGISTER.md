# Source Register

Use this register to separate source evidence from modeled assumptions and recommendations.

| Source | Type | Intended use | Public / restricted | Status |
|---|---|---|---|---|
| Utility asset inventory | GIS / asset registry | asset identifiers, type, geometry, material, age | typically restricted | not connected |
| CCTV / condition inspections | inspection system | structural/operational condition evidence | typically restricted | not connected |
| CMMS / work orders | maintenance system | failures, cleaning, repairs, maintenance burden | typically restricted | not connected |
| Hydraulic model | model output | capacity and surcharge evidence | restricted | not connected |
| SSO / incident records | operational/regulatory | failure consequence and history | varies | not connected |
| CIP / bid history | planning/procurement | unit costs and project readiness | varies | not connected |
| Public engineering reports | published documents | benchmark methods/costs/case studies | public | add as verified |

## Source rules
1. Record the publisher/owner, title, date, and retrieval location for each public source used in a report or cost benchmark.
2. Do not copy restricted utility data into this public register.
3. Distinguish current utility facts from historical facts and generic planning assumptions.
4. Link every case-study fact or cost benchmark to a traceable source before presenting it as verified.
